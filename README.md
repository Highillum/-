ОПИСАНИЕ
Готовая HTML-страница для приёма пожертвований и переводов. Поддерживает отображение реквизитов СБП (по номеру телефона), криптовалютных адресов (TRC20, ERC20, TON) и банковских карт (Альфа-Банк, ПСБ, МТС, ГазПРОМБанк, ЦУПИС) с функцией копирования в один клик.

ВОЗМОЖНОСТИ
СБП — перевод по номеру телефона +7 987 773-37-26
Криптовалюта — USDT TRC20, ETH/USDT ERC20, TON/USDT
Банковские карты — 5 российских банков
Копирование в 1 клик — каждая кнопка копирует реквизит в буфер обмена
Три слоя копирования — Clipboard API → execCommand → ручное выделение
Визуальная обратная связь — зелёная кнопка при успехе, красная при ошибке
Всплывающие уведомления (toast) — подтверждение копирования
Ручное выделение — клик по тексту реквизита выделяет его для Ctrl+C
Адаптивный дизайн — корректно отображается на телефонах и ПК
Киберпанк-стиль — тёмная тема, неоновые акценты, моноширинный шрифт
